# ПР 1. Технічне завдання

## Назва та призначення
HabitFlow — адаптивний вебзастосунок для формування звичок і відстеження їх виконання. Варіант №19: «Трекер звичок», основна сутність — «Звичка», обов’язкова функція — календар виконання і статистика.

## Аудиторія
Студенти 16–25 років, люди з регулярними особистими цілями, користувачі мобільних пристроїв.

## Конкуренти (попередня UX-оцінка; потребує ручної перевірки актуальних версій)
| Сервіс | Переваги | Недоліки / обмеження для нашої аудиторії |
|---|---|---|
| Habitica | Гейміфікація, мотивація | Багато елементів, складний початок |
| Loop Habit Tracker | Простота, статистика | Переважно мобільний сценарій, обмежена веб-доступність |
| Streaks | Фокус на серіях, чистий UI | Прив’язка до екосистеми Apple, платна модель |

## Ключові сценарії
1. Створити звичку → бачити її в каталозі.
2. Позначити виконання → побачити його в календарі.
3. Відкрити статистику → переглянути прогрес за 7 днів.

## Sitemap
`/` огляд → `/habits` каталог → `/items/:id` деталі; `/calendar` календар; `/stats` статистика; `/contact` форма; `*` 404.

## Функціональні вимоги
FR-01 список звичок; FR-02 додавання; FR-03 редагування через API; FR-04 видалення; FR-05 відмітка виконання за датою; FR-06 календар; FR-07 статистика за тиждень; FR-08 пошук; FR-09 фільтр за категорією; FR-10 світла/темна тема; FR-11 контактна форма; FR-12 повідомлення про помилки завантаження.

## Нефункціональні вимоги
NFR-01 mobile-first для 360/768/1280 px; NFR-02 семантичний HTML і клавіатурна навігація; NFR-03 клієнтська та серверна валідація; NFR-04 ціль Lighthouse ≥90 в усіх 4 категоріях на mobile (не підтверджено); NFR-05 зрозумілі повідомлення про помилки; NFR-06 збереження в JSON у демо.

## Технології
React, Vite, React Router, CSS Grid/Flexbox, Node.js, Express, JSON, Vitest.

## Дані
Habit: `id: string`, `name: string`, `category: string`, `frequency: daily|weekly`, `icon: string`, `completedDates: string[]` (ISO YYYY-MM-DD).
