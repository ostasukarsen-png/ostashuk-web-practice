## Оптимізації, закладені в код
Mobile-first media queries, SVG-іконки, production build Vite, семантичні заголовки, skip-link, фокус, prefers-reduced-motion, service worker. Додатково перевірити розділення чанків, WebP/AVIF і SEO для кожного SPA-маршруту.
