# ПР 2–3. UX/UI

## Персони
**Олена, 19, студентка:** хоче регулярно читати й займатися спортом; забуває про цілі; користується телефоном. **Андрій, 25, працівник:** хоче бачити тижневий прогрес; не любить складні інтерфейси; ноутбук і телефон.

## User stories
1. Як студент, хочу додавати звички, щоб мати список цілей.
2. Як користувач, хочу відмічати виконання, щоб бачити прогрес.
3. Як користувач, хочу календар, щоб бачити регулярність.
4. Як користувач, хочу графік за тиждень, щоб оцінювати результати.
5. Як користувач, хочу темну тему, щоб комфортно користуватися ввечері.

## User flow
Головна → Мої звички → Нова звичка → Заповнення → Збереження → Позначення виконання → Календар → Статистика.

## Wireframe (опис для відтворення у Figma)
Desktop 1440px: header 80px; hero 2 колонки; 3 KPI-картки; список звичок. Mobile 375px: вертикальна hero; одна колонка KPI; навігація з бургер-меню. Для каталог/деталі/контакти — відповідні картки й форми. Сітка 12 колонок desktop, 4 mobile. Створити окремі low-fi фрейми без кольору та hi-fi фрейми у Figma.
